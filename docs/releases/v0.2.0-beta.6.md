# v0.2.0-beta.6 — Native editor middle-click

Full keeps left-click editing and search behavior, while middle-clicking inside
the address editor now follows Firefox's native input behavior and leaves the
selected tab open. Middle-click closing on browsing tabs remains native.

No hover-to-edit behavior was added. Lite remains CSS-only. Existing AutoConfig,
enterprise policies and security configuration are protected by the installer.

The change passed 27 Firefox motion/middle-click checks and 38 native Full tab
checks on Firefox 159.0. The updated Full and Lite packages include SHA-256
checksums.
