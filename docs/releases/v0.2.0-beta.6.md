# v0.2.0-beta.6 — Full and Lite

Source version: 2026.11.16-31.

## Full edition

- Click the selected tab to open the native address/search field. Hover only
  highlights the tab.
- Middle-click inside the editor now follows native Firefox behavior and keeps
  the tab open. Middle-click on browsing tabs still closes them natively.
- Includes the animated privileged editor and GitHub release updater, which
  stages a compatible Full update for the next normal restart.
- Full requires a compatible, unclaimed AutoConfig slot. Existing AutoConfig,
  enterprise policies and security settings are never overwritten; conflicts
  recommend Lite.

## Lite edition

- Profile CSS only, with no AutoConfig loader, privileged script or updater.
- Click a background tab to select it, then click its title to edit with the
  native address field. Ctrl+L, Alt+D and F6 also work. Hover does not open it.
- Middle-click inside the inline editor keeps the tab open. Native middle-click
  closing remains available on the exposed tab edge.
- CSS anchor layout is used where available; narrow windows and unsupported
  layouts use a separate address row.

Both editions keep the Monterey appearance, adaptive theme colors, rounded tabs
and native Firefox security controls. Multiple tabs use smaller capsules while
the single-tab layout stays wide. The release includes separate Full and Lite ZIPs
and `SHA256SUMS.txt`.

## Validation

The Lite click-to-edit change passed 69 real Firefox checks with a lab AutoConfig
and policy active. Full middle-click/motion and editable-tab suites passed 27 and
38 checks on Firefox 159.0. The earlier beta.6 Linux run failed in legacy classic
layout fixtures before reaching release archive checks; Windows native Firefox
checks passed.
