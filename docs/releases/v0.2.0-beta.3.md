# WhiteSur Monterey Adaptive v0.2.0-beta.3

This beta brings the Safari-inspired compact tab update and introduces a separate **Lite edition**. Both ZIPs include `Install.cmd`, `Uninstall.cmd`, and installation checks. Close Firefox, extract the ZIP you want, and run its `Install.cmd`.

## Choose your edition

- **Full:** compact tabs show titles and favicons while browsing. Click a background tab to select it, then click the selected tab to expand Firefox's native address/search field. Requires Firefox 158+ with horizontal tabs. Your existing Firefox and usual shortcuts work; Windows requests administrator approval only when the loader needs access to a protected installation directory.
- **Lite:** the classic userChrome CSS theme with normal tabs and a separate address bar. No editable-tab script, AutoConfig loader, Firefox copy, or extra shortcut is installed. It enables custom stylesheets in the selected profile and leaves Firefox installation files unchanged. Older Firefox and existing AutoConfig setups can use this edition.

The Full archive also includes `Install-Lite.cmd` to select its classic CSS mode. Lite's own `Install.cmd` and direct PowerShell installer always select CSS-only mode. To switch editions, close Firefox and run the other edition's installer. Custom CSS and unrelated preferences are preserved. Switching Full to Lite disables editable tabs and removes their profile script/state; an existing shared loader is left in place for other Full profiles and stays inactive for Lite.

## What's changed

- Normal compact tabs while browsing; only the edited tab expands, with adaptive sizing that preserves room for neighbouring tabs.
- Smooth editor expansion/collapse, new-tab entrance, and tab-close effects, respecting reduced-motion settings.
- Middle-click the search field to close its tab. Releasing outside the field cancels the gesture.
- The + button works while editing and opens a new tab ready for typing; returning to the original tab preserves its unfinished address.
- Double-click empty toolbar space to maximise or restore the window, including narrower restored windows. Tabs, buttons, input, and tab reordering retain their normal behaviour.
- Google/Qwant shortcuts, native search/security icons, suggestions, and adaptive theme colours remain available in Full.
- Future version-tag releases automatically build and attach **both Full and Lite ZIPs**, with SHA-256 checksums, after the test suites pass.

## Validation

Validated on Windows 11 with Firefox 158.0.1: 49 installer checks; 33 editable-tab, 18 search-mode, 25 motion/interaction, and 19 native titlebar checks; 16 package groups. The release-package suite additionally extracts both ZIPs, tests the Lite CMD launcher and direct installer, verifies Full-to-Lite upgrades and unchanged Firefox files, and starts both editions in disposable Firefox instances. GitHub Actions reruns release validation before publishing the downloads.
