# Full without AutoConfig

Full now defaults to **Compatible**, installing only profile CSS. Existing
AutoConfig such as `zscaler.cfg`, enterprise policies and security settings remain
untouched. No loader or administrator approval is needed for the default method.

CSS anchors attach Firefox's real address field to the selected tab where
supported. Full retains the centred single-tab capsule, centred tab titles and
favicons, native suggestions/security controls, adaptive colours and native
Windows buttons. Hover the selected tab and click to edit, or use Ctrl+L.
Narrow windows, pinned selections and engines without anchors use separate
address/tab rows; vertical tabs retain their sidebar.

The legacy JavaScript method remains an explicit `-InstallationMethod AutoConfig`
option for clean Firefox 158+. Existing cfg/pref-loader files are never rewritten;
modified files cause a refusal recommending Compatible. Lite remains Classic.

Compatible uses native focus, Escape and tab animation behavior. Exact second
click activation, scripted close snapshots, middle-click closing inside the
input and hard-coded `g`/`q` routing remain legacy-only. See the
[full feature matrix and alternatives analysis](../COMPATIBILITY.md).

Real Firefox testing uses isolated profiles and copies with actively loaded
synthetic AutoConfig and enterprise policy. See
[the validation record](../VALIDATION-beta.5.md) for evidence and limitations.
Both ZIPs now include upstream license texts as well as attribution notices.
