# v0.2.0-beta.5 — Full and Lite

Source version: 2026.11.10-28.

Full uses guarded AutoConfig for click-to-edit, middle-click closing inside the
editor, custom motion and the new optional GitHub release updater. Hovering only
highlights. Lite uses profile CSS without a loader, privileged scripts or updater;
Ctrl+L edits, and browsing tabs retain native middle-click closing.

Multiple tabs are smaller while the lone-tab capsule stays wide. Lite uses CSS
anchor positioning where supported and separate address/tab rows in narrow or
unsupported layouts. Both preserve adaptive colours and native security controls.

Full checks releases daily, verifies and stages a newer compatible Full ZIP, and
applies during normal shutdown for next startup. Current customChrome.css survives.
Full-to-Lite migration cancels queued updates. AutoConfig/policies/security files
are never overwritten; Full refuses conflicts and recommends Lite.

See [edition limits](../COMPATIBILITY.md), [updater trust/recovery](../AUTO-UPDATES.md)
and [real Firefox validation](../TESTING.md).
