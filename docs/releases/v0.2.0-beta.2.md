# WhiteSur Monterey Adaptive v0.2.0-beta.2

## Editable tabs in your existing Firefox

Close Firefox, extract the attached Windows theme ZIP, and run `Install.cmd`. The installer adds the editable-tab loader directly to your existing Firefox and opens the installed profile. **Your usual Firefox shortcuts work.** Your profile, extensions, bookmarks, and Firefox update mechanism are retained.

For Firefox installations in protected folders such as Program Files, approve the Windows administrator prompt. Only the loader-file helper runs with administrator rights; profile detection and theme installation stay with your original user. Writable per-user installations need no elevation.

Editable tabs require Firefox 158+ with horizontal tabs. Missing or older Firefox, conflicting AutoConfig loaders, denied administrator approval, and setup errors stop installation before replacing the profile theme. Classic CSS is an explicit choice: `Install.cmd -ClassicToolbar`.

`Install.cmd -FirefoxPath "C:\path\to\firefox.exe"` selects another existing installation. A separate Firefox copy is available only when explicitly requested with `-RuntimeDirectory`. When upgrading from beta.1, the previous unmodified owned WhiteSur shortcut is removed. An old separate Firefox copy can be removed manually after closing it and switching to your usual Firefox.

Theme updates preserve `customChrome.css`, existing theme backups, and unrelated preferences. Uninstall removes the profile theme and preferences; the shared loader remains for other profiles and ignores profiles without this theme's marker.

## Validation

Validated on Windows 11 with Firefox 158.0.1: **49 Windows PowerShell 5.1 installer checks, 25 native Firefox checks, and 16/16 package groups passed.** Installer coverage includes the existing Firefox path, no additional shortcut or binary copy, updates, uninstall, the administrator helper, simulated protected-folder handling, CMD argument forwarding, and setup failures. Native Firefox tests exercise the default installer against a disposable existing installation.
