# WhiteSur Monterey Adaptive v0.2.0-beta.2

## Automatic editable-tab installation

Close Firefox, extract the attached Windows theme ZIP, and run `Install.cmd`. The installer sets up the editable-tab runtime and opens WhiteSur Firefox with your installed profile automatically. Use the **WhiteSur Firefox - <profile>** desktop shortcut on later launches.

Editable tabs require Firefox 158+ with horizontal tabs. If Firefox is missing, too old, contains a conflicting AutoConfig loader, or runtime setup fails, installation reports an error before replacing your profile theme. It no longer reports a successful classic installation when editable tabs could not be enabled.

`Install.cmd` now accepts installer options. Use `Install.cmd -FirefoxPath "C:\path\to\firefox.exe"` to select another Firefox installation, or `Install.cmd -ClassicToolbar` to explicitly choose the classic CSS toolbar. Direct PowerShell installations can use `-Launch` to open the configured browser.

The original Firefox installation is preserved. Its original shortcut still opens the classic toolbar. Theme updates preserve `customChrome.css`, existing theme backups, and unrelated preferences.

## Validation

Validated on Windows 11 with Firefox 158.0.1: 36 Windows PowerShell 5.1 installer checks, 25 native Firefox checks, and 16/16 package check groups. Coverage includes automatic launch with the correct executable and profile, CMD argument forwarding and failure exit codes, install/update/uninstall, explicit classic mode, and runtime failures leaving the profile theme untouched.
