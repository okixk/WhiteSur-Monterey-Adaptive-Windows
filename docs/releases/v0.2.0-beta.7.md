# v0.2.0-beta.7 — Full and Lite

Source version: 2026.11.18-32.

## Full edition

Full keeps its guarded AutoConfig editor, tab animations and GitHub release
updater. Existing AutoConfig, enterprise policies and security settings are
never overwritten.

## Lite edition

Lite remains profile CSS only, with no AutoConfig loader or privileged script.
When one of two tabs closes, the remaining tab now expands and moves to the
center together. The transition was verified at narrow, medium and wide window
sizes, closing either tab.

Both editions include adaptive colors, rounded tabs, native Firefox security
controls, and their own ZIP archive with SHA-256 checksums.
