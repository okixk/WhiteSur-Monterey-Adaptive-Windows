# WhiteSur Monterey Adaptive v0.2.0-beta.4

This beta refines Full's Safari-inspired compact toolbar: a smaller centred single-tab capsule, centred titles and address/search text, and favicons directly beside the text. Both Full and Lite ZIPs include `Install.cmd`, `Uninstall.cmd`, and installation checks.

## What's changed in Full

- A lone ordinary tab becomes a centred capsule up to 580 CSS pixels wide, with responsive sizing in narrower windows and room for + and window dragging. Pinned tabs retain their icon size.
- Opening a second tab smoothly moves the capsule into the compact layout. Closing back to one smoothly returns it to the centre. Existing editor fades, new-tab entrances, and close effects remain; reduced-motion settings are respected.
- Tab titles, addresses, searches, and placeholders are centred. The favicon sits immediately to the left of the text and follows native value changes. Very cramped fields prioritise the native controls and readable input.
- Firefox keeps its original input, autocomplete, selection, long-address scrolling, search-engine selector, security icons, and page actions. Click a background tab to select it, then click the selected tab to edit. Ctrl+L, Alt+D, and F6 open editing directly.
- Existing + clicks while editing, middle-click closing in the field, adaptive colours, and native maximise/restore gestures remain available.

## Choose your download

- **Full ZIP:** editable/searchable tabs, including these refinements. Requires Firefox 158+ with horizontal tabs. Installs its loader into your existing Firefox; your usual shortcuts work. Only writing loader files in protected installation directories requires administrator approval.
- **Lite ZIP:** the classic userChrome CSS theme with a separate address bar, without editable tabs, their script/style, a Firefox loader, a browser copy, or an extra shortcut. It leaves Firefox installation files unchanged. This update does not add the Full-only tab behaviour to Lite.

Close Firefox, extract the ZIP you want, and run its `Install.cmd`. Full also includes `Install-Lite.cmd`. Both preserve custom CSS, unrelated preferences, and theme backups. Switching Full to Lite disables/removes the profile's editable-tab files/state; an existing shared loader remains available to other Full profiles and stays inactive in Lite.

`SHA256SUMS.txt` contains checksums for both archives. The release workflow runs the test suites and publishes both editions together.

## Validation

Native Firefox coverage includes 38 editable-tab checks, 27 motion/interaction checks, 18 centred-text/favicon checks, 18 search-engine checks, and 19 Windows titlebar checks. Packaging coverage installs both extracted ZIPs into disposable profiles, launches both editions in Firefox, checks Full-to-Lite upgrades, and verifies Lite leaves Firefox files untouched. Installer and classic-layout/package checks also run before the downloads are published.
